# MOOC STM32H5 Secure Manager 

Disclaimer: This material was created in 2024 and is delivered as is.

## MOOC purpose 

Learn the steps to install STM32Trust TEE Secure Manager on your STM32-based devices and achieve robust security. Furthermore, examine the advanced STM32H5 security features, like product state, debug authentication, and STiROT, which are specifically engineered to address the diverse security needs of your design.

## Prerequisites
- STM32H573I-DK board
- USB TypeC cable
- PC with MS Windows with preinstalled the following software:
    - STM32CubeMX in version at least 6.9.2
    - STM32CubeIDE in version at least 1.13.2
    - STM32CubeProgrammer in version at least 2.14.0
    - STM32CubeH5 library in version at least 1.1.0 + Patch 1.1.1
    - STM32TrustedTEE-SM
    - Any terminal application with support for Ymodem (i.e. TeraTerm)
